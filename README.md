# 115 资源管理器

一个精简的应用（Web + iOS 原生壳）：扫码授权 115、读取网盘已有目录、对比 TMDB 集数与海报、分享链接增量转存、磁力云下载。iOS App 内置原生网络层，直接请求 115，不依赖后端网关。

## 功能

- 115 扫码授权：生成二维码后用 115 App 扫码确认；取消只是收起二维码，5 分钟内扫码结果仍然有效；不要求手动复制 Cookie。
- 授权失效提示：任意页面收到 401 都会弹出全局“重新授权”窗口，不会打断当前页面。
- 授权会话持久化：成功后复用本地缓存，15 分钟内不再请求 115 校验；只有缓存过期才重新验证。
- 读取 115 网盘：内置目录浏览器，可把网盘中已有的剧集目录直接加入资源库。
- 后台任务进度：添加目录时窗口可以立即关闭，右上角显示扫描/同步进度，完成后自动恢复。
- 多层目录递归：支持 `资源库/动漫/斗罗大陆/...S01E01.mp4` 这类嵌套结构，扫描带请求间隔防止触发 115 风控。
- 集数对比：递归扫描 115 目录并解析 `S01E01`、`第01集` 等文件名，展示“已保存 X / TMDB Y 集”，支持按季查看。
- 海报与 TMDB 关联：搜索并关联 TMDB 条目后显示海报、简介与总集数。
- 分享链接增量导入：按“文件名 + 大小”过滤已缓存文件，命中后复用原 115 目录，点击保存转存。
- 本链接文件名替换（保存时真正改名）：例如把 `dldl.s01e200.mp4` 保存到 115 时重命名为 `斗罗大陆2绝世唐门.s01e200.mp4`（扩展名保持不变），随后立即按新名称建立本地索引，无需额外同步。
- 资源详情支持“按规则批量重命名”：递归处理资源目录内所有文件，后台任务带进度，扩展名不一致自动跳过。
- 资源详情可单独“同步 TMDB 数据”：新增集数后只刷新 TMDB 海报、简介、总集数与剧集缓存，不重复扫描 115。
- 未命中时可选择已有资源的目录，并按 SxxExx 集数过滤（例如已存 1-146，新链接只选出 147-150）。
- 长文件列表虚拟滚动，切换 Tab 不丢失当前页面状态。
- 磁力云下载：把磁力链接/下载地址推送到 115 离线下载，并查看任务状态。
- 移动端适配：底部导航 + 卡片布局，手机、平板、电脑共用同一页面。
- PWA：支持添加到主屏幕，离线时保留静态页面。

## 启动（Web 模式）

```bash
python3 -m venv .venv
.venv/bin/pip install flask requests
cd frontend && pnpm install
cd ..
npm run dev
```

一条命令会同时启动 Flask（`8767`）和 Vite（`5173`），按 `Ctrl-C` 会一起终止。

## TMDB

在“设置 → TMDB”填入 TMDB API Key（v3 auth）后，资源详情里可以搜索剧集并关联，显示海报和总集数。未配置时不影响 115 读取、导入与云下载。

## 115 授权

登录只支持扫码授权，已移除账号密码入口。扫码后把授权会话持久化（Web 在服务端，iOS 在系统原生 Cookie 存储），并在有效期内复用；只有缓存过期才重新校验。

## TMDB

TMDB 使用 API Key（v3 auth），不是刷新令牌。在“设置 → TMDB”填写 v3 API Key 即可；如果使用 v4 的 Access Token 也可以，两者都能用于读取详情和搜索。

## iOS App（TrollStore）

前提：一台装了完整 Xcode 的 macOS（不是只有 Command Line Tools），并已安装 CocoaPods/SPM 网络正常。

```bash
cd frontend
pnpm build:ios
```

生成 `frontend/ios-build/115-resource-manager-unsigned.ipa`，用 TrollStore 安装即可。App 内会使用原生 HTTP 直连 115，不需要部署 Flask 后端；TMDB API Key 在“设置 → TMDB”里填写。

如果只是调试工程：

```bash
cd frontend
pnpm cap:ios
```

## 数据说明

- 资源名称、文件索引、115 目录映射与集数统计持久化在本地 SQLite / IndexedDB。
- 移除资源只会删除本地索引，不会删除 115 云端文件。
